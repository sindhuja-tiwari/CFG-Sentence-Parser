# CFG-Sentence-Parser
🎯 Overview
This parser demonstrates fundamental NLP concepts by breaking down sentences into their grammatical components (noun phrases, verb phrases, prepositional phrases, etc.) and displaying their hierarchical relationships as parse trees. It's particularly useful for understanding syntactic ambiguity - where a single sentence can have multiple valid interpretations.
✨ Features
Grammar Components:

Noun Phrases (NP) - Subjects and objects with determiners, pronouns, and relative clauses
Verb Phrases (VP) - Action verbs with complements and modifiers
Prepositional Phrases (PP) - Spatial and relational descriptions
Relative Clauses - Embedded descriptive phrases
Infinitives - "to + verb" constructions

Capabilities:

Handles syntactic ambiguity (multiple valid parse trees)
Visualizes sentence structure hierarchically
Supports complex sentences with nested phrases
Displays all possible grammatical interpretations
